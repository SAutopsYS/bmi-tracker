# Demo video script (2–3 minutes)

BMI Tracker by **IV Innovations Private Limited**.

**Recording target:** Chrome browser (Flutter Web) at phone width (~390–480 px).  
**Mode:** Local Demo Mode. Do not claim cloud sync.

**Prep**

1. `DEMO_MODE=true` and `DEMO_EMAIL=demo@bmitracker.demo` in `.env` (or bundled `.env.example` for Web).
2. `flutter run -d chrome`
3. Cold start so splash appears.
